# 2026-10-25 开发日志

## 今日成果：v1.1「节假日日历与调休提醒」

### 背景

v1.0 只有「节假日不提醒」，且 holiday-cn 同步时把调休上班日（`isOffDay=false`）直接丢弃，整个数据模型没有「调休」概念；提醒按自然星期匹配课程，调休周六无法按「上周四的课」提醒。用户确认需求：调休日按指定周几上课（默认按当天）、节假日管理改为日历形式。

### 关键设计决策

1. **存储沿用差集模式**：放假与调休各走一套「官方 ∪ 手动添加 − 手动删除」，同步只重写官方集合 → 手动改动天然不被覆盖，与 v1.0 语义完全兼容。新增 DataStore key：`makeup_official / makeup_added / makeup_removed / makeup_weekdays`（元素 `yyyy-MM-dd=4` 表示按周四）。
2. **「按周几」映射只能用户设置**：holiday-cn 只给日期不给按周几，同步只标日期；`makeup_weekdays` 永不被同步触碰。UI 上点调休日期时用 chips 引导选择。
3. **调休不受「节假日不提醒」开关控制**：放假跳过提醒看开关；调休改的是「按哪天的课表」，属于日历事实。
4. **放假优先于调休**：同一日期两种标记冲突时 `effective()` 求差时放假日从调休集合剔除，避免歧义。
5. **簿记逻辑做成纯函数**（`HolidayLogic.setDayStatus` 等）供 Repository 复用并被单测覆盖——这是本版唯一的数据正确性风险点。

### 遇到的问题

- **星期编号约定踩坑**：java.time 周一=1..周日=7，周六是 6 不是 7。项目代码全用正确约定，我单测预期写错被测试抓住——单测第一天就值回票价。
- `EffectiveDayOfWeek` 初版没校验日期是否真在调休集合里，残留映射会错误改写普通日；改为先查 `makeupDays` 再取映射，并补了单测用例。
- 模拟器 ABI：构建产物按 ABI 拆分，x86_64 模拟器要装 `app-universal-debug.apk`（或对应 x86_64 包）。

## 关键决策与过程

1. **迁移测试的 schema 收割**：`app/schemas/` 只有 4.json（exportSchema 是 v1.2 才开的），且翻历史发现**初始提交就是 Room version 3**——v1/v2 只存在于未发布的开发期，无 schema 可考。用 `git worktree` 检出 v1.1 状态（38abc87），临时开 `exportSchema = true` 重新跑 KSP 收割出 3.json，androidTest 里 MigrationTestHelper 建真实 v3 库验证 3→4 展开。教训：**exportSchema 应该从第一天就开着**，现在 1/2 版的迁移只能靠代码review 保证
2. **解析器单测抓到两个既有行为细节**（按现状记录进测试，不当 bug 修）：节次列占位「节」会被表头检测当成列名吃掉整行；周次缺省兜底的 rangeIn 会把节次列数字一起算进周次区间 min-max
3. **测试数据踩坑**：weeks 存储格式是升序逗号集合（"1,2,...,16"），写测试时顺手写成区间 "1-16" 会被 WeeksCodec.parse 解析成空集——测试第一天就把这个格式直觉纠正了
4. **TextUnit 没有 + 运算符**：GridMetrics 初版在 LessonCard 里 `metrics.subSp + 1.sp` 编译不过，行高收进 GridMetrics 统一管理（更干净）
5. **Glance defaultWeight 只在 Row/Column 作用域内可用**：周视图列组件初版在自己函数体里调 `GlanceModifier.defaultWeight()` 编译不过，改为在 Row 内容 lambda 里求值后当参数传入
6. **detekt 搁置（记录在 TODO）**：1.23.8（Maven Central 最新）CLI 内置的 Kotlin 运行时解析不了本机 JBR 25（`JavaVersion.parse("25.0.2")` 崩），全机只有 JDK 26/25 没有 ≤21；AGP lint 已清零全部错误作为替代门禁
7. **lint 真修清单**：gradle.properties 冒号转义、CourseListScreen 组合中读 StateFlow.value、androidx.exifinterface 替换、monochrome 图标、mipmap-anydpi-v26 冗余限定等；版本升级类提醒（OldTargetApi/NewerVersionAvailable）保留为提示
8. **周视图小组件验证**：模拟器真实走了一遍桌面长按 → Widgets → 添加；切「显示周末」后 5 列↔7 列即时联动（Widgets.updateAll 双刷链路生效）
9. **自动备份落盘实测**：MediaStore 写 Documents/苦瓜课表/ 真实可见；连点 8 次「立即备份」验证滚动保留——只剩最近 7 份
