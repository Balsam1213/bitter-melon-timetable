# 更新日志

## v1.2（2026-10-25）

**自定义周次 + 课表分享图片 + 课程搜索**

- **自定义周次**：课程时间段支持任意周集合（如「1-8, 11-16 周」），单双周降级为快捷选择。数据模型从「区间 + 每周/单周/双周」改为周集合单列（Room v3→v4，旧数据自动展开迁移，含已验证的 v1.1→v1.2 升级路径）
- 周次编辑改为 WeeksPicker 多选网格（全学期/单周/双周/清空快捷键），编辑页与导入预览共用
- 周次标签智能生成：全学期不显示、"3-17周 单周"、"1-8,11-16周" 游程分段
- 冲突检测改为周集合求交；JSON 导出升为 v2 格式（weeks 为主、旧区间字段推导兼容，v1.0/v1.1 仍可导入）
- **课表分享图片**：当前周课表渲染为 PNG（浅色、含学期/周次/日期/课程色块），可保存到相册（Pictures/苦瓜课表）或经系统分享面板发送
- **课程搜索**：全部课程页按名称/教师/地点过滤
- 小组件日期固定中文 locale（修复英文系统显示 "10月25日 Sunday" 混排）
- 清理：删除 PatternChips/NumberField 无消费方组件；Room 开启 exportSchema（app/schemas 存档）
- 单测：新增 WeeksCodecTest（编解码往返/游程分段/标签生成），WeekLogicTest 改为集合语义（共 35 个）
- `versionName` 1.2 / `versionCode` 3

## v1.1（2026-10-25）

**节假日日历与调休提醒**

- 节假日管理从列表改为月历：放假日标「休」（红）、调休上班日标「班·四」（暖橙，显示按周几）；点日期弹底部编辑层增删改；今天描边
- 调休上班日可设置「按周几上课」（默认按当天自然星期），课前提醒、桌面小组件、课表表头徽章均按该周几的课表走
- 预置 2026 官方调休上班日 6 天（国办发明电〔2025〕7号，与 holiday-cn 2026.json 核对一致）
- holiday-cn 在线同步改为双通道：同时解析放假日与调休上班日，按年分别替换官方集合；手动改动永不被同步覆盖
- 小组件法定放假日显示「今天放假，好好休息」
- 设置页节假日区块改为「日历管理」入口（含放假/调休天数统计）；同步按钮补上结果反馈（已同步/无变化/失败）
- 修复：通知 ID 从课程名哈希改为闹钟序号，同名课程提醒不再互相顶掉
- 修复：提前量滑条 0–45 扩为 0–120（5 分钟一档），与 README 一致
- 修复：README 删除失实的「Android 12+ 动态取色」描述（主题一直固定品牌紫）
- 清理：删除无 UI 入口的 `AppSettings.defaultMode`、等价于 GLOBAL 的 `ReminderMode.NOTIFICATION`、无用变量 `numbered`
- 新增云备份/换机迁移规则（`backup_rules.xml` + `data_extraction_rules.xml`）
- 新增单元测试 23 个（HolidayLogic 差集簿记、JSON 双通道解析、WeekLogic 周次/冲突）
- `versionName` 1.1 / `versionCode` 2
