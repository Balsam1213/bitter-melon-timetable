# 更新日志

## v1.3（2026-10-25）

**显示体验 + 工程加固**

- **课表显示设置**：字号三档（小/标准/大，作用于课程卡文字与网格行高，与系统字体缩放叠加）；紧凑模式只压行高与留白、不缩字号，两者正交；应用主题四选一（兰紫默认/靛蓝/松绿/玫粉），浅深两色即时生效——课程色板与节假日徽章色不随主题，分享图片排版保持固定
- **周视图小组件**：第二个桌面小组件（约 4×3），本周一天一列概览：今天列高亮、列内课名+地点、放不下的收「+N」、放假日显「休」、调休日按映射周几取课；列数跟随「显示周末」设置；数据变更与今日小组件一起联动刷新
- **每日自动备份**：当前学期 JSON 自动存到「文档/苦瓜课表」，滚动保留最近 7 份；可关闭、可「立即备份」，设置页显示上次备份时间；全程本机不联网
- **工程加固**：Gradle version catalog 统一依赖管理；AGP lint 纳入门禁并清零全部错误（含 androidx.exifinterface 替换、图标 monochrome 单色层等）；单测 35 → 81（解析器/导入映射/周小组件数据全覆盖）；新增 Room v3→v4 迁移的 instrumented 测试（旧 schema 从 v1.1 历史提交收割）
- **重构**：TimetableScreen/CourseEditScreen 大文件按职责拆分（纯移动，行为不变）；节假日网络同步抽独立层 HolidaySyncClient；删除同步路径调试日志
- 周网格尺寸与字号集中于 GridMetrics 管理；网格布局对设置变化即时重排
- 修复：发布后用户反馈——系统大字体（≥1.5 倍）下主题/字号选择按钮被挤成竖排变形；选择行改 FlowRow，放不下整颗换行（模拟器 1.5 倍字体复现验证）；Release 资产已同步更新
- `versionName` 1.3 / `versionCode` 4

## v1.2（2026-10-25）

**自定义周次 + 课表分享图片 + 课程搜索**

- **自定义周次**：课程时间段支持任意周集合（如「1-8, 11-16 周」），单双周降级为快捷选择。数据模型从「区间 + 每周/单周/双周」改为周集合单列（Room v3→v4，旧数据自动展开迁移，含已验证的 v1.1→v1.2 升级路径）
- 周次编辑改为 WeeksPicker 多选网格（全学期/单周/双周/清空快捷键），编辑页与导入预览共用
- 周次标签智能生成：全学期不显示、"3-17周 单周"、"1-8,11-16周" 游程分段
- 冲突检测改为周集合求交；JSON 导出升为 v2 格式（weeks 为主、旧区间字段推导兼容，v1.0/v1.1 仍可导入）
- **课表分享图片**：当前周课表渲染为 PNG（浅色、含学期/周次/日期/课程色块），可保存到相册（Pictures/苦瓜课表）或经系统分享面板发送；分享弹层打开即完全展开，预览与按钮一屏可见
- **课程搜索**：全部课程页按名称/教师/地点过滤
- 小组件日期固定中文 locale（修复英文系统显示 "10月25日 Sunday" 混排）
- 清理：删除 PatternChips/NumberField 无消费方组件；Room 开启 exportSchema（app/schemas 存档）
- 单测：新增 WeeksCodecTest（编解码往返/游程分段/标签生成），WeekLogicTest 改为集合语义（共 35 个）
- `versionName` 1.2 / `versionCode` 3

## v1.1（2026-10-25）
