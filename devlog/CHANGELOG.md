## v1.5（2026-11-15）

**备份恢复 + 首启向导 + 提醒窗口修正 + WebView 再收紧**

- **从备份恢复**（设置 → 数据 → 从备份恢复）：自动扫描「文档 / 苦瓜课表」备份目录，列表展示备份时间、学期名称、开学日期与数据量，解析失败文件标红；也可从任意位置选择 JSON 文件（换机场景）。恢复前自动校验 JSON 格式、备份版本（比应用更新的备份拒绝并提示升级）与学期字段；预览展示将恢复的数据；两种模式——**合并恢复**（备份课程并入目标学期、重复跳过）与**完整恢复**（替换目标学期的课程/学期字段/节次，二次确认）。执行在单个 Room 事务里，失败整体回滚、原有数据分毫不动
- **恢复前自动快照**：完整恢复前先把目标学期当前数据存为「恢复前快照-*.json」到备份目录，快照写失败直接中止恢复；快照与备份一起参与 7 份滚动清理
- **首启三步向导**（新装且无学期时自动出现，每步可跳过）：① 创建学期（名称/开学日期/总周数按今天日期预填可改）→ ② 选择导入方式（Excel/截图/教务网/JSON 备份恢复/手动）→ 识别与确认复用导入预览 → ③ 就绪页（本周课表已生成 + 课前提醒开关引导）。完成/跳过后落 `onboarding_done` 标记，已有学期自动跳过向导
- **导入预览时间冲突提示**：预览页新增条目间冲突检测（同天 + 节次相交 + 周次相交），琥珀色标注「与 XX 时间冲突」，仅提示不拦导入；`ImportPlanner.conflictsAmong` 纯函数 + 单测
- **提醒窗口修正**：`ReminderPlanner` 从「今天起 8 个自然日」改为严格 **7×24 小时时间戳窗口**（now..now+7d，边界含）——修复周一早 8 点会把下周一晚上的课也排进提醒的越界问题；补边界单测（恰好 7 天 / 超 1 分钟 / 跨周末 / 跨月 / 跨年）

- **WebImportBus 加固**：解析结果改为 `consume()` 读后即清，未发布就退出页面时清空遗留，防止旧数据被下次误消费；架构文档明确「仅限 WebImportScreen↔ImportScreen 使用，新导入入口不得引用」
- **本地优先措辞**：README 双语首屏、设置页「关于」、课表空状态从「完全离线」改为「本地优先」，消除与联网功能矛盾的表述；需求文档同步
