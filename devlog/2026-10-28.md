## 今日主题：P0 安全与可靠性加固（外部审查反馈落地）

针对一轮外部代码审查提出的四个 P0 问题逐项修复，共 6 个提交。

### 审查发现与处置

1. **教务网 WebView 明文/证书/导航风险**：此前明文 HTTP 是三层叠加放行（Manifest `usesCleartextTraffic` + WebView 混合内容兼容 + URL 归一化放行 `http://`，且连 `file://` 都放行、`allowFileAccess=true`），`shouldOverrideUrlLoading` 完全未重写。处置：平台层保留明文许可（http 校园站兼容是既定需求，networkSecurityConfig 无法白名单用户动态输入的域名），风险收敛到 WebView 交互层——scheme 只放行 http/https、明文加载前弹窗警告（含服务端重定向兜底，在 `onPageStarted` 拦截）、跳转站外确认（同注册域自动放行，`edu.cn` 等多段后缀取后 3 段的启发式，覆盖高校跨子域 SSO）、SSL 弹窗补充凭据窃听风险提示并按 host 做会话级记忆（子资源错误不再反复弹窗）、`allowFileAccess/allowContentAccess` 关闭、退出时 `CookieManager.flush()` 保登录态。
2. **Release 用 debug 签名**：生成 30 年期 RSA-2048 keystore（仓库外 `~/keystore/`，密码进 gitignore 的 `keystore.properties`），release 优先正式签名、缺文件回退 debug 并警告。**换签名意味着旧版用户升级需卸载重装**，v1.4 发版说明要写清。`apksigner verify` 已确认新包签名生效。
3. **README「唯一联网功能」失实**：中英文 README 与 Manifest 权限注释都改成如实描述（教务网导入 + 节假日同步都联网），新增「联网行为说明」表。
4. **导入无事务、重复导入重复插入**：`importEntries` 包 `db.withTransaction`；新增 `ImportPlanner` 纯逻辑层（校验星期/节次/周次、周次全超界判无效——旧逻辑反而原样保留死课、与已有课程完全重复的条目跳过）；完成反馈逐项展示「新增/跳过重复/无效原因」。
5. **提醒决策零测试**：抽出 `ReminderPlanner` 纯函数（与 AlarmManager 解耦），13 个单测覆盖假日跳过/调休映射/跨午夜提前量/上限 50 截断等；`ReminderScheduler` 只剩取数与排闹钟，行为不变。
6. 解析器异常输入单测补齐（空文件/坏 JSON/缺列/周次倒序与超大值）。单测 81 → 117，androidTest 新增 ImportRepositoryTest 6 个。

### 踩坑记录

1. **Manifest 属性列表中间不能插 XML 注释**——注释放在 `<application>` 元素前面，放在属性之间直接 manifest merger 解析失败
2. **Compose AlertDialog 内 TextField 的 adb 输入**：`input keyevent`（MOVE_HOME/MOVE_END/DEL）进不了组合输入框，只有 `input text` 能落到光标处；清空内容要靠长按 → Select all → 输入替换。另外长按用 `input swipe x y x y 1200` 实现

## 下午：P1 可用性优化 + v1.4 发版

按上午批下的计划做 P1 四项，版本升 1.4 / versionCode 5，正式签名首发。

### 关键决策

1. **自动建学期改「先确认再入库」**（用户选定方案）：无学期时导入先弹「先建个学期」窗（学期名预填建议值/开学日期预填本周一/20 周，均可改），确认后才建。根源是旧逻辑静默把开学日期写死为本周一——周次与提醒错位的最大隐患；JSON 备份路径（importFromDoc 自带学期合并语义）与 fresh 路径不受影响。
2. **备份/通知提示只挂设置页**（用户选定）：不动首页（首页无横幅基建，新增组件+判定逻辑改动面中等，收益低）。
3. **备份状态三态**：`BackupOutcome`（Success/NoSemester/Failed）+ `last_backup_ok` 键。关键兼容点：**旧版本只写时间不写 ok，`ok==null` 视为成功**，否则老用户全部误报红字。NoSemester 不写状态——新装机第一天不该看到「备份失败」。
4. **预览逐条标记复用入库校验**：`ImportPlanner.validate` 本就是纯函数（private），改 public 后预览与入库同一口径，装载时无效条目 `include=false`，用户改完字段仍可手动勾——不做「禁止导入无效条目」的硬限制。

### 顺手修的缺陷

- MediaStore 写入无 runCatching：磁盘满/权限异常会让 Worker 直接 FAILED（连 retry 都没有）

- JSON 空条目静默进预览（预览区不渲染也无提示）→ 明确报错
- 编辑弹窗 WeeksPicker 周数上限从硬编码 20 改为目标学期真实周数
