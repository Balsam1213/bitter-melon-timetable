# 2026-10-26 开发日志

## v1.3 发布后热修：大字体下主题按钮变形

### 现象与根因

用户真机反馈（换一台手机也复现）：设置页「应用主题」的「玫粉」被挤成两行竖排、按钮变形。模拟器默认字体一直正常——根因是**用户系统字体缩放大（国产 ROM 大字体档，约 1.5 倍）**，每颗 chip 随 sp 放大变宽后，四颗总宽超出屏幕，而 `Row` 不会换行只会挤压最后一个子项的 label。

### 复现与修复

- 复现：`adb shell settings put system font_scale 1.5` → 模拟器 1.3 倍还没到临界，**1.5 倍完美复现**（玫粉折两行，与用户截图一致）
- 修复：字号与主题两组选择行 `Row` → `FlowRow`（课程调色板已有先例）——放不下时**整颗 chip 换行**（1.5 倍下变 3+1 排列），任何 fontScale/屏宽下都不挤压变形
- 验证：1.5 倍字体模拟器实测通过；恢复 1.0 后布局不变；81 单测 + lint 全绿

### 教训

前两轮只验证了默认字体。**涉及设置页/表单的 UI 要在 `font_scale 1.5` 下过一遍**——国产 ROM 用户开大字体的比例不低。已把这条加进 docs/03 的验证注意项（下轮顺手补）。
