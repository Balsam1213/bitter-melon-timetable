# 设计规范

> UI/UX 与文案约定。改界面前先对一遍这里，保持一致性。

## 1. 主题与配色

- **品牌紫主题，浅/深两套固定色**（`ui/theme/Theme.kt`）：primary 浅 `#8A6FE8` / 深 `#C9B8FF`。**不使用动态取色**，保证品牌一致（README 不得再宣称动态取色）
- 课程卡片颜色用 `CourseColors.PALETTE` 10 色调色板（色相间隔大、明度统一），**不做任意取色**
- 语义色只用 Material3 角色（`primary/secondaryContainer/error/outline...`），**例外**：节假日徽章用固定语义色（见下）

### 节假日徽章语义色（`ui/theme/HolidayBadgeColors.kt`）
固定不随主题生成，日历惯例「红=休、暖橙=班」：

| 徽章 | 浅色 bg / fg | 深色 bg / fg | 用途 |
|---|---|---|---|
| 休 | `#F9DEDC` / `#410E0B` | `#8C1D18` / `#F9DEDC` | 法定放假日 |
| 班 | `#FFDFB0` / `#4A2E00` | `#5D4200` / `#FFE08B` | 调休上班日（「班」/「班·四」） |

使用处：节假日日历格子、主课表表头日期徽章。两处必须同色。

## 2. 布局与组件

- **页面结构**：`Scaffold + TopAppBar`（返回箭头 `Icons.AutoMirrored.Filled.ArrowBack`，contentDescription 一律中文）+ 单列内容。设置类页面用 `SectionCard`（标题 + 卡片内分组）
- **图标**：只用 material-icons-core 已有集合（ArrowBack/Add/Close/Delete/Refresh/MoreVert/KeyboardArrowLeft/Right/DateRange/Search/List），不够先用文字按钮
- **底部弹层**：详情/编辑优先 `ModalBottomSheet`（课程详情、日期编辑）；破坏性操作（恢复默认等）必须 `AlertDialog` 二次确认
- **日历页**：周一开头 7 列网格（复用 `WEEK_HEADERS`），今天 primary 描边，月切换 ‹ › + 「今天」按钮；不放图例（信息在点开的弹层里）
- **空状态**：必须有文案 + 引导（如「先在应用里设置学期」），不允许白屏

## 3. 文案规范

- 全部简体中文，硬编码在 Compose 里（无 strings.xml，不做 i18n）；标点用中文全角
- **口语化、说人话**：说明文字面向学生，避免术语。例：「你手动改动过的日期不会被同步覆盖」而不是「用户编辑具备持久化优先级」
- 命名口径统一：
  - 「放假」= 法定放假日（不叫「节假日/假期」）；「调休」= 周末补班日
  - 调休默认项叫 **「默认」**（= 官方安排，按当天自然星期上课），不叫「按当天」
  - 「节次」不叫「课时」；「学期」的周次从「第 1 周周一」起算
- 按钮：动词开头（「标记为放假日」「取消调休标记」「立即同步官方安排」）
- 徽章文案：休 / 班 / 班·四（「·四」= 按周四上课，用 DOW_LABELS 短格式）

## 4. 交互约定

- **导入必须先预览确认**：任何来源入库前都有预览页，逐条可勾选可编辑
- 数据变更即联动：写课程/设置/节假日后立即重排提醒 + 刷新小组件（用户无感）
- 长耗时/联网操作要有结果反馈（Snackbar：已同步/无变化/失败），不静默
- 手势：课表左右滑切周；重操作（删除学期/恢复默认）需确认

## 5. 小组件

- Glance 实现，`SizeMode.Exact` 按实际高度自适应行数
- 深浅色跟随系统；圆角 20dp 卡片、时间轴节点样式
- 放假日显示「今天放假，好好休息」；调休日按映射周几取课
- 已知问题：日期标签用系统 locale 格式化（英文系统显示 "Sunday"），v1.2 固定中文 locale
