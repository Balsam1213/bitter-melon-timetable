## 1. 安装与升级

### 1.1 选择 APK

要求 Android 8.0 及以上。到 [Releases 最新版](https://github.com/Balsam1213/bitter-melon-timetable/releases/latest) 按设备架构下载：

| APK 文件 | 适用设备 |
|---|---|
| `app-arm64-v8a-release.apk` | 绝大多数近年的手机（**推荐**） |
| `app-armeabi-v7a-release.apk` | 较老的 32 位手机 |
| `app-x86_64-release.apk` | 模拟器 / x86 设备 |
| `app-universal-release.apk` | 不确定架构时的通用包（体积更大） |

不确定就选 `arm64-v8a`；装不上（提示「不兼容」）再换 universal 包。

### 1.2 升级

- **v1.4 及之后**：直接用新版 APK 覆盖安装，课表数据自动保留。
- **v1.3 及更早 → v1.4+**：签名从 debug 换成了正式签名，**系统不允许直接覆盖**。请按这个顺序操作：
  1. 在旧版本里「设置 → 导出当前学期为 JSON」把课表导出（或找到「文档 / 苦瓜课表」里的每日自动备份）；
  2. 卸载旧版本（这会删除本地数据，所以第 1 步必须先做）；
  3. 安装新版，在「设置 → 从备份恢复」里选刚才的 JSON 文件恢复。
- 以后升级都遵循 1.4 的签名，不需要再卸载。

### 1.3 安全提醒

请只从本项目 GitHub Releases 页面下载 APK，不要使用来路不明的转载安装包。

## 2. 首次使用向导

新安装并打开应用后，会进入三步向导（每一步都可以跳过，之后随时能补做）：

### 第 1 步 · 创建学期

- 学期名称、第 1 周周一（开学日期）、总周数都已按今天日期**自动预填**，例如 9 月打开会预填「2026-2027学年 第一学期」、本周一、20 周。
- 请核对两件事：**开学日期**（决定「今天是第几周」，算错提醒就会错位）和**总周数**。
- 不想现在建也可以「跳过」，直接导入时没有学期会再弹窗帮你建。

### 第 2 步 · 选择导入方式

明确列出全部入口：Excel/CSV 文件、课表截图识别、教务网导入（需联网）、JSON 备份恢复（换机场景）、手动添加课程。选择后会进入对应的流程，解析结果都会**先预览确认再写入**。

### 第 3-4 步 · 识别与确认

解析完成后进入预览页：

- 顶部显示共解析出多少条记录；
- **无效条目**（星期/节次/周次不合法）红字标注原因并默认不勾选，点条目可以改字段后手动勾选；
- **时间冲突**（两条记录同一天、节次和周次重叠）以琥珀色提示「与 XX 时间冲突」，仅供确认，不会拦截导入；
- 底部按钮「导入所选 N 门课程」确认写入。

### 第 5 步 · 进入课表

导入完成回到向导就绪页：显示学期与课程数量、本周课表已生成；并提供「开启课前提醒」开关，建议打开（若系统弹窗询问通知权限，请选择允许）。点「完成，进入课表」结束向导。

## 3. 导入课表

五种方式入口都在「设置 → 数据 → 导入课表」（或课表空状态页）：

| 方式 | 说明 |
|---|---|
| Excel / CSV | 支持 `.xlsx` 和 `.csv`（UTF-8 / GBK 编码均可）。有表头按关键词识别列，无表头按「星期、节次、课程、教师、地点、开始周、结束周、单双周」固定顺序读取。模板：[课程表导入模板.csv](../模板/课程表导入模板.csv) |
| JSON 备份文件 | 本应用导出的格式（见 [示例](../模板/课程表示例.json)），恢复备份也可以走[「从备份恢复」](#9-备份与恢复)获得更好体验 |
| 课表截图识别 | 离线中文 OCR（模型内置 APK，不联网）。要求截图包含「周一~周日」表头与节次列；识别结果务必人工核对 |
| 手动添加 | 逐门添加课程 |
| 教务网导入 | 需联网。见下节 |

### 教务网导入

1. 在导入页选「教务网导入」（默认打开西南交大教务网，点击地址栏可改成任意学校的网址）。
2. 在应用内登录教务网，进入「我的选课记录」或「本学期周课表」页面。
3. 点右上角「确认导入」，应用抓取当前页面并解析出课程，进入统一的预览确认流程。

安全相关的行为（详见 [架构文档](02-architecture.md)）：

- 明文 http 地址、证书异常、跳转到其他网站，都会先弹窗告知风险、确认后才继续；
- 页面只在本地解析，课表数据不上传；
- 「⋮」菜单里可以清除教务网登录状态（Cookie / 站点存储 / 缓存）；
- 「允许混合内容」「接受第三方 Cookie」默认关闭，个别学校系统需要时可在菜单临时打开。

## 4. 学期与节次时间

- **学期管理**（课表页 → 学期名）：新建（可复制旧学期节次）、编辑（名称/开学日期/总周数）、设为当前、归档、删除。删除会一并删除该学期的课程与节次，不可恢复。
- **节次时间**（课表页 → 节次时间）：每节课的起止时间自由编辑、增删；午休/晚休空档由上下午划分自动推导，不需要单独设置。
- 开学日期填「第 1 周的周一」；填开学当天也可以，应用会自动归到那一周的周一。

---

## 5. 课程管理

- 在课表空白格点按/拖选可直接新建课程，时段自动预填。
- 一门课可以有多个时间段；周次支持**任意集合**（如「1-8, 11-16 周」，单双周只是快捷选择）。
- 自定义颜色、教师、地点、备注；保存时自动检测时间冲突并提示。
- 「全部课程」页支持按名称 / 教师 / 地点搜索。
- 点击课表格子查看详情，可编辑或删除。

---

## 6. 课前提醒

- 「设置 → 课前提醒」：全局开关 + 提前量（0–120 分钟，默认 15 分钟）。
- 单门课程可在课程编辑页单独关闭提醒。
- 提醒通过**精确闹钟**（`setAlarmClock` 通道）触发，重启手机、覆盖安装后自动重排，深度休眠（Doze）与厂商省电不会合批延迟。
- 通知带横幅、声音与震动；今天在法定假日列表里则当天不提醒。
- 若通知权限或精确闹钟权限受限，设置页会红字提示并提供一键跳转开启。
- 提醒计划的窗口是**未来 7×24 小时**、最多 50 条；更晚的课程会在之后的重排中补上。

---

## 7. 节假日与调休

- 「设置 → 节假日 → 日历管理」：日历视图里放假日标「休」（红），调休上班日标「班」。
- 放假日当天不发提醒；调休上班日按你指定的周几的课表提醒（点「班」徽章可改「按周几」）。
- 数据按国务院年度安排预置；联网时自动同步最新官方安排（holiday-cn 数据源，次年安排公布后自动补全，每天最多尝试一次）。
- 你手动添加/删除的日期**永不被同步覆盖**；「恢复默认」清空全部手动改动与已同步数据。

---

## 8. 桌面小组件

- **「今日课程」**：今天的课程列表，正在上的课高亮；点击进入应用；法定放假日显示「今天放假」，调休上班日按指定周几显示。
- **「本周课程」**（约 4×3）：一天一列的本周概览，今天列高亮；列数跟随「显示周末」设置。
- 长按桌面空白处 → 添加小组件（或小工具）→ 找到苦瓜课表。
- 数据变化（导入、改课、改节次）后小组件自动刷新。

## 9. 备份与恢复

### 9.1 自动备份

- 默认开启：每天自动把**当前学期**导出为 JSON，存到「文档 / 苦瓜课表」（系统「文件」应用 → Documents → 苦瓜课表），只保留最近 7 份。
- Android 8.x 设备上备份存在应用私有目录（卸载即清，仅作兜底），因此 **Android 8.x 用户建议定期手动导出**。
- 「设置 → 数据」里可关闭自动备份、点「立即备份」马上备份一次；上次备份的成功/失败状态会显示在旁边。

### 9.2 从备份恢复

入口：「设置 → 数据 → 从备份恢复」。

1. **自动扫描**：应用自动扫描「文档 / 苦瓜课表」备份目录，列出每个备份的**时间、学期名称、开学日期、数据条数**；解析失败的文件会标红并显示原因。
2. **选择备份**：点列表里的一项；也可以点「从文件选择备份…」选任意位置的 JSON 文件（换机场景：用微信/网盘把备份文件传到新手机后选它）。
3. **检查格式与版本**：应用自动校验 JSON 格式、备份版本与学期字段；版本比当前应用更新的备份会拒绝恢复并提示先升级应用。
4. **预览要恢复的数据**：显示备份学期信息与数据量。
5. **选择恢复方式与目标学期**：
   - **合并恢复**（默认）：把备份课程合并到所选学期；与现有课程完全重复的条目自动跳过；学期信息与节次不变。
   - **完整恢复**：用备份**替换**目标学期——课程清空后按备份重建，学期名称、开学日期、总周数与节次时间也以备份为准。适合「备份才是对的，当前数据乱了」的场景。
6. **确认**：完整恢复有二次确认框（明确会清空哪个学期）。
7. **执行**：恢复在**单个数据库事务**里进行，任何一步失败都会整体回滚——**原有数据分毫不动**，并提示失败原因。

### 9.3 恢复前快照（防误操作）

选择**完整恢复**时，应用会先把目标学期的当前数据自动存一份快照到「文档 / 苦瓜课表」（文件名「恢复前快照-学期名-时间.json」），**快照写失败会直接中止恢复**。万一恢复后发现不对，用快照文件再走一遍恢复即可找回。快照与普通备份一起参与「保留最近 7 份」的滚动清理，重要快照建议手动另存。

### 9.4 换机迁移

1. 旧手机：设置 → 立即备份（或导出当前学期为 JSON）。
2. 把 JSON 文件通过微信 / 网盘 / 数据线传到新手机。
3. 新手机：安装苦瓜课表 → 设置 → 从备份恢复 → 「从文件选择备份…」→ 选择文件 → 完整恢复（推荐，学期信息一并还原）。

## 10. 常见问题 FAQ

**Q：周次数不对 / 显示「假期」？**
检查「学期管理」里的开学日期：它必须是第 1 周的周一。改对之后周次、提醒都会跟着对。

**Q：提醒没响？**
按顺序检查：① 设置里「开启课前提醒」是否打开；② 系统通知权限；③ 精确闹钟权限（设置页有红字引导）；④ 国产 ROM 的自启动与后台弹出界面权限；⑤ 提醒窗口是未来 7 天，8 天后的课不提前排。

**Q：导入的 Excel / 截图识别结果很乱？**
先看模板列顺序是否一致；识别类结果请在预览页逐条核对，无效条目会标红，点条目可直接修改字段。

**Q：教务网打开是白屏？**
个别学校管理后台有 CSS 缺陷，应用会自动尝试修复并刷新（页面会提示）；白屏不影响导入，直接点「确认导入」即可。请确认已登录且停在「选课记录」或「周课表」页面。

**Q：想清空教务网登录记录？**
教务网导入页右上角「⋮ → 清除教务网登录状态」。

**Q：备份文件在哪？**
系统「文件」应用 → Documents（文档）→ 苦瓜课表。

**Q：卸载会丢数据吗？**
会（备份文件在「文档 / 苦瓜课表」的 Android 9+ 设备除外）。换机/重装前请先导出 JSON 或确认自动备份可访问。

**Q：旧版 .xls 为什么不支持？**
旧格式是私有二进制格式，请在 Office/WPS 里另存为 `.xlsx` 或 `.csv` 再导入。

## 11. 隐私说明

- 无账号体系，课表数据仅存于本机数据库与 DataStore；应用唯一申请的敏感权限是 `INTERNET`。
- 联网仅两处且都由你主动触发：教务网导入（页面只在本地解析）与节假日同步（3 个 https 公共镜像，失败静默回退内置数据）。
- 自动备份与恢复全程本机完成，不上传任何服务器。
