# 需求说明

> 苦瓜课表（Bitter Melon Timetable）的产品需求基线。改动需求先改这里，再动代码。

## 1. 产品定位

- **完全离线**的大学课程表 Android App：无账号、无登录、数据仅存本机
- 默认面向国内高校学生（预置西南交大教务网，可改任意学校）
- 唯一联网功能：教务网导入（应用内 WebView）与节假日官方安排同步（holiday-cn），课表数据永不上传

## 2. 核心用户故事

1. 学生把课表导进 App（Excel / 教务网 / 截图 / 手动），**先预览确认再入库**，导入错误可改
2. 打开 App 即见本周课表，自动算「今天第几周」，左右滑切周
3. 上课前收到通知提醒，哪怕国产 ROM 省电也不迟到（`setAlarmClock`）
4. 法定假日不提醒；调休上班的周末按学校安排的周几上课并正常提醒
5. 换机/备份：导出 JSON → 新机导入

## 3. 功能需求（v1.3 现状）

### 3.1 课表与课程
| 需求 | 状态 | 说明 |
|---|---|---|
| 周课表网格视图 | ✅ | 切周/今天高亮/非本周灰显/重叠课弹层/空白格拖选建课 |
| 一门课多时间段 | ✅ | 地点在时间段级 |
| 任意周集合（如 1-8, 11-16 周） | ✅ | v1.2 起为周次集合；每周/单周/双周是快捷选择 |
| 课程颜色 | ✅ | 10 色预设调色板（不做任意取色） |
| 时间冲突检测 | ✅ | 保存时周集合求交检测，可「仍然保存」 |
| 课程搜索 | ✅ | 全部课程页按名称/教师/地点过滤 |

### 3.2 学期与节次
- 多学期：开学日期（第 1 周周一）+ 总周数 → 周次全部计算得出；设当前/归档/删除/复制节次
- 节次起止时间自由增删改（午休/晚休由上下午空档自动推导，不落库）

### 3.3 导入导出与备份
- xlsx / CSV（UTF-8、GBK）/ JSON / 截图 OCR（ML Kit 中文，离线）/ 教务网 WebView（Jsoup 解析）→ **统一预览确认页**，逐条勾选可编辑
- **入库前统一校验与去重**：星期/节次非法、周次为空或全超学期总周数的条目不写库，并在完成反馈中说明原因；与已有课程完全重复的条目（名称+教师+星期+节次+周次+地点）自动跳过；整个入库在事务中执行，中途失败不留半截数据
- 导出：当前学期 JSON
- **每日自动备份（v1.3）**：当前学期 JSON 存 `Documents/苦瓜课表/`（26–28 存应用私有目录），滚动保留最近 7 份，可关闭 / 立即备份
- 明确不做 `.xls`（README 已给转存替代方案）
- **教务网导入安全边界**：明文 http 加载前、跳转到其他网站前、证书异常时都必须用户确认（弹窗写明凭据窃听风险），不做静默放行；WebView 禁用本地文件与 content 访问，只放行 http/https

### 3.4 提醒
- 全局提前量 0–120 分钟（5 分钟一档）；单课可关闭
- 7 天窗口最多 50 个 `setAlarmClock` 精确闹钟（Doze 免疫）；无权限降级 `setExactAndAllowWhileIdle`
- 数据变更/开机/覆盖安装/每次触发后全量重排（幂等）
- **节假日不提醒**（受开关控制）；**调休上班日按用户设置的周几的课表提醒**（不受开关控制，默认按当天）
- 触发时刻二次拦截：排完闹钟后才改节假日列表的兜底

### 3.5 节假日与调休（v1.1 重做）
- 数据 = 官方安排（预置 2026 放假 34 天 + 调休 6 天；联网按年同步 holiday-cn）与用户手动的差集合成，**手动改动永不被同步覆盖**
- 日历式管理页：放假「休」（红）/ 调休「班·四」（暖橙）/ 今天描边；点日期弹层增删改
- 小组件与主课表表头显示同样徽章；放假日小组件显示「今天放假」

### 3.6 课表分享（v1.2 新增）
- 菜单「分享课表图片」：当前查看周渲染为浅色长图（学期/周次/日期表头 + 课程色块，重叠课分栏）
- 可保存到相册（Pictures/苦瓜课表，API 29+）或经系统分享面板发送；弹层打开即全展开
- 排版与配色固定，不随字号档位 / 紧凑模式 / 应用主题变化（发给别人看的图要稳定）

### 3.7 显示设置（v1.3 新增）
- 课表字号三档：小 / 标准 / 大（作用于课程卡文字与网格行高，与系统字体缩放叠加）
- 紧凑模式：只压行高与留白，不缩字号，与字号档位正交
- 应用主题四选一：兰紫（默认）/ 靛蓝 / 松绿 / 玫粉，浅深两色即时生效；只换应用界面配色，
  课程色板与节假日徽章色不随主题

### 3.8 其他
- 桌面小组件（Glance）两个：**今日课程**（时间轴、进行中高亮、按高度自适应）、**周视图本周课程**（v1.3，一天一列、今天高亮、列数跟随显示周末）
- 深色模式跟随系统；显示周末开关（只影响 UI 与周视图列数，不影响提醒）
- 数据变更自动联动提醒重排与两个小组件刷新（`Graph.onDataChanged`）

### 3.9 首次体验与状态反馈（v1.4）
- **首次导入引导**：无学期时导入先弹「先建个学期」确认窗（学期名预填建议值、开学日期预填本周一、总周数预填 20，均可改），确认后才建学期入库；不再静默用本周一当开学日
- **预览逐条标记**：预览页对每条解析记录做校验（与入库同口径 `ImportPlanner.validate`），无效条目红字标注原因并默认不勾选，改字段后可手动勾选
- **失败原因可读**：所有解析异常翻译为中文（坏 xlsx / 坏 JSON / IO），OCR 空结果、JSON 空条目都有明确报错，不显示英文异常类名
- **状态反馈（设置页）**：备份状态三态（尚未备份 / 成功时间 / 失败红字+引导手动导出）；通知被系统关闭、精确闹钟未授予（31+）时红字提示 + 一键跳系统设置；无当前学期不误报备份失败

## 4. 非目标（明确不做）

- 账号/云同步/社区功能
- 多语言 i18n、平板/横屏专项适配（受众为中文手机用户）
- iOS 版
- 任意取色器、自定义主题色（预设主题可选，自由配色不做）

## 5. 已知限制（面向用户）

1. 旧版 `.xls` 不支持，需另存 `.xlsx`
2. 截图 OCR 效果依赖图片清晰度，务必人工确认
3. 国产 ROM 需手动允许「自启动」「后台弹出」，否则通知可能延迟
4. 「按周几上课」官方数据源不提供，需用户在日历中手动设置
