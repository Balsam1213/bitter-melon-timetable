# 开发日志

记录苦瓜课表的开发事项与待办。规范类文档（需求、技术架构、设计规范、流程）见 [docs/](../docs/)。

## 结构

- `CHANGELOG.md` —— 按版本记录每次发布的内容
- `TODO.md` —— 待办与候选功能（按优先级）
- `YYYY-MM-DD.md` —— 当日开发日志（做了什么、为什么、遇到的问题）

## 约定

1. **每天开工建一个日期文件**，先写当天目标，收工时补结果；重要决策记录「为什么」，不只是「做了什么」。
2. **完成一项就更新 `TODO.md`**（勾掉或移入下个版本），不要攒到发版才整理。
3. **发版时更新 `CHANGELOG.md`**，同时核对 `app/build.gradle.kts` 的 `versionName` / `versionCode` 与设置页显示（设置页读 `BuildConfig.VERSION_NAME`，只需改 gradle）。
4. 日志只增不改：写错的内容划掉更正（`~~错~~ → 对`），不删除历史记录。
